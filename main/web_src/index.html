管理模式

不自动退出

热点与管理页面会保持开启，直到设备长按 OK 退出。关闭页面后，编辑权限为原浏览器保留 2 分钟。

使用提示

  • 图片仅支持 JPG / PNG。浏览器会完成裁剪、压缩并转换为 RGB565，设备端不做解码。
  • 手机连接设备热点时，部分 Android 机型会暂时切走移动数据；如果管理页可用但外部链接打不开，请先断开热点再访问小黑盒。
  • NFC 为无源 NTAG213 标签，固件不能改写。请复制 NFC 内容，用支持 NFC 的手机写入标签。
  • 支持手动 JSON 导出/导入（含图片）；不提供自动备份、ZIP、历史版本或 OTA。导入不会自动回滚。

NFC 入口

卡片上的 NTAG213 是无源标签，固件无法直接改写。这里配置的是要写入标签的内容；设备会显示内容并生成二维码，方便手机写入或复制。

导出备份

把个人资料、游戏列表、NFC 配置和全部图片打包成一个 JSON 备份文件。图片以 PPIM 原始数据 Base64 保存，不包含热点密码。

导入备份

导入会覆盖设备上的个人资料、游戏、NFC 与相关图片。建议先导出当前数据；导入需要编辑权限。

说明

  • 备份文件包含个人资料和图片，请妥善保管。
  • 导入不提供自动回滚；失败时可能已写入部分数据，建议先导出当前状态。
  • 手动备份之外，本产品仍不提供自动备份、ZIP、历史版本或 OTA。
