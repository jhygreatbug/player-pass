管理模式

不自动退出

热点与管理页面会保持开启，直到设备长按 OK 退出。关闭页面后，编辑权限为原浏览器保留 2 分钟。

使用提示

  • 编辑内容先保留在当前浏览器，点击底部“保存更改”后一次性写入设备。断开热点再连回来不会覆盖本地未保存的内容。
  • 图片仅支持 JPG / PNG。浏览器会完成裁剪、压缩并转换为 RGB565，设备端不做解码。
  • 游戏搜索和玩家游玩列表来自 Steam，需要手机能访问互联网；部分 Android 机型连接热点时会断开移动数据，此时仍可手动添加游戏。
  • 手机连接设备热点时，部分 Android 机型会暂时切走移动数据；如果管理页可用但外部链接打不开，请先断开热点再访问。
  • 支持手动 JSON 导出/导入（含图片）；不提供自动备份、ZIP、历史版本或 OTA。导入不会自动回滚。

导出备份

把个人资料、游戏列表和全部图片打包成一个 JSON 备份文件。图片以 PPIM 原始数据 Base64 保存，不包含热点密码。

导入备份

导入会覆盖设备上的个人资料、游戏与相关图片。建议先导出当前数据；导入需要编辑权限。

说明

  • 备份文件包含个人资料和图片，请妥善保管。
  • 导入不提供自动回滚；失败时可能已写入部分数据，建议先导出当前状态。
  • 手动备份之外，本产品仍不提供自动备份、ZIP、历史版本或 OTA。
